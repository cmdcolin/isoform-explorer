# Isoform explorer

If this transcript is the one being made, what does the protein lose?

For every reviewed human protein with alternative isoforms in UniProt, the
site lists what each isoform's sequence lacks from the canonical protein:
residues, UniProt features, folded residues in the AlphaFold DB model and
predicted partner interfaces. A sibling of
[Interface explorer](https://cmdcolin.github.io/interface-explorer/).
