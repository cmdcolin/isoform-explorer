# A post on LEF1, where three isoforms lack a whole predicted interface

The blog has no post whose case is a predicted partner interface, though the
interface rows are on every gene page that has one. LEF1 has 28 confident
interface residues with β-catenin (CTNNB1), and isoforms 3, 4 and 7 each lack
all 28 (`site/data/genes/LEF1.json`, checked 2026-11-16). Which of the three
the post follows is open; they differ in length (284, 214 and 303 against the
canonical's 399), so the one whose other losses are easiest to state is
probably the one to use.

**Hero:** a Wnt pathway cartoon, drawn by code like the others. The blog's
existing kinds are listed in [PAGES.md](../../reference/PAGES.md), and a post
whose hero would repeat one gets dropped, so check that list first.

**What the post may not say.** [CLAIMS.md](../../reference/CLAIMS.md) has the
rules that bite here: a kept interface is not binding, and a lost one is not
loss of binding. No isoform was modelled with a partner, so the post can say
which residues the isoform lacks and nothing about what LEF1 then does. The Wnt
cartoon is explaining the pathway to a reader, not asserting the isoform's place
in it, and the caption has to keep that separation.
